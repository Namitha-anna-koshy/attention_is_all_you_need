# Attention Is All You Need 🧠

### *Because apparently, the best way to understand Transformers is to build one.*

A **Transformer implemented from scratch in PyTorch**, inspired by the paper **[Attention Is All You Need](https://arxiv.org/abs/1706.03762)**.

No `nn.Transformer()`. No magic. Just attention, matrices, and a questionable number of tensor dimensions.

## 🚀 What This Project Includes

* Scaled Dot-Product Attention
* Multi-Head Attention
* Positional Encoding
* Encoder & Decoder
* Masked Self-Attention
* Cross-Attention
* Feed-Forward Networks
* Residual Connections & LayerNorm
* Autoregressive generation
* Attention visualization
* Interactive demo with Gradio
